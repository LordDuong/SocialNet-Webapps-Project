📋 Project Overview

This is a Social Network Web Application built with PHP and MySQL. The application allows users to create accounts, log in, view other users' profiles, and manage their personal information.

✨ Features

🔐 User Authentication

Secure login and registration system with password hashing using bcrypt.

👥 User Profiles

View and manage user profiles with customizable descriptions and information.

⚙️ Settings Management

Users can edit their profile information and update their descriptions.

🏠 Home Feed

Browse all users in the system and view their profiles.

🛠️ Technologies Used

Frontend

HTML5, CSS3, JavaScript (ES6+)

Backend

PHP 7.4

Database

MySQL / MariaDB

Web Server

Nginx
